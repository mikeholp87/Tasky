Install with APT

Add the signed Tasky repository once. APT will keep it updated with your system packages.

Before installing, review the key verification steps and compare the full fingerprint with a trusted project announcement.

View the repository key fingerprint 

sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://mikeholp87.github.io/Tasky/tasky-archive-keyring.asc \
  | gpg --dearmor \
  | sudo tee /usr/share/keyrings/tasky-archive-keyring.gpg >/dev/null
echo 'deb [arch=amd64 signed-by=/usr/share/keyrings/tasky-archive-keyring.gpg] https://mikeholp87.github.io/Tasky stable main' \
  | sudo tee /etc/apt/sources.list.d/tasky.list >/dev/null
sudo apt update
sudo apt install tasky

To update later: sudo apt update && sudo apt upgrade. To remove: sudo apt remove tasky.

Processes in context

Search, sort and inspect process trees. End or suspend tasks with safeguards for critical system processes.

Private by design

Monitoring stays on your computer. Tasky works offline; network access is used only by the optional internet benchmark.

Built for Linux desktops

Native packages support Ubuntu 22.04 and newer, and Debian 12 and newer on amd64. KDE Plasma and GNOME are supported.
