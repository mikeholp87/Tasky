Free and open source system monitor

Know what your computer is doing.

Tasky is a fast, private task manager and system monitor for Linux and Windows. Follow live CPU, memory, disk and network use, inspect and control processes, and benchmark your machine, all without sending anything off your computer.

Everything about your system in one quiet app

Tasky keeps the essentials one click away and stays fast with thousands of processes.

Live overview

CPU, memory, storage and network cards with 60-second graphs, plus larger history views from 60 seconds to one hour.

A fast process table

Instant search by name, PID, command line or user. Filter presets, a process tree, sortable columns and heat mapping.

Safe process control

End, suspend, resume or reprioritize processes. Critical system processes are protected, and risky actions ask first.

Process details

CPU, memory and disk history, working directory, child processes and TCP and UDP connections for any process.

Benchmarks

Repeatable CPU and GPU compute tests, a disk benchmark on Linux, and run history with safe comparison between results.

Internet test only runs after you confirm

Alerts and tray

Rules such as “CPU above 80% for 20 s” with desktop notifications, and a tray icon with a live CPU and memory summary.

Linux tools

See and manage systemd services, and mount or unmount external drives from the Storage page. System-critical items stay locked.

Install with APT

Add the signed repository once and APT keeps Tasky updated with your other packages. Verify the signing key before you trust it.

  1. Install the prerequisites

    sudo apt update
sudo apt install ca-certificates curl gnupg

  2. Download the key and check its fingerprint

    The fingerprint printed by gpg must be exactly this. Also compare it with the one in the README on GitHub.

    48F8 0DD5 6C89 66D2 59B2 11C8 1D4B 05C4 EEA1 F6B4 
    curl -fsSLo /tmp/tasky-archive-keyring.asc \
  https://mikeholp87.github.io/Tasky/tasky-archive-keyring.asc
gpg --show-keys --with-fingerprint /tmp/tasky-archive-keyring.asc

  3. Add the repository

    gpg --dearmor --output /tmp/tasky-archive-keyring.gpg \
  /tmp/tasky-archive-keyring.asc
sudo install -D -m 0644 /tmp/tasky-archive-keyring.gpg \
  /usr/share/keyrings/tasky-archive-keyring.gpg
echo 'deb [arch=amd64 signed-by=/usr/share/keyrings/tasky-archive-keyring.gpg] https://mikeholp87.github.io/Tasky stable main' \
  | sudo tee /etc/apt/sources.list.d/tasky.list >/dev/null

  4. Install Tasky

    sudo apt update
sudo apt install tasky

    Update later with sudo apt update && sudo apt upgrade. Remove with sudo apt remove tasky. Prefer a single file? Download Tasky.deb and its SHA-256 checksum from GitHub Releases.

Questions

Does Tasky collect or send any data?

No. There is no telemetry and it works fully offline. The only network use is the optional internet benchmark, which contacts Cloudflare’s speed endpoints only after you press its button and confirm.

Can it end any process?

It can end, force end, suspend, resume and reprioritize processes you are allowed to control. Critical system processes and Tasky itself are protected by the backend, and risky actions show a confirmation first.

How are service and drive changes authorized?

On Linux, changes to system services use your desktop’s own authorization prompt. System and internal partitions are never offered for unmounting.

Which Linux desktops work?

KDE Plasma and GNOME on Wayland are tested. Other desktops are not verified. The tray icon needs StatusNotifier or AppIndicator support. See the platform support notes in the repository for GNOME window-position details.

Where do I report a bug or a security issue?

Open an issue on GitHub. For security reports, read the security policy first.
