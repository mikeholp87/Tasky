# Unsafe Rust and FFI audit

Audit date: 2026-11-03. Inventory includes first-party Rust source and tests;
dependencies/native drivers require separate upstream review. This is a source
review plus platform compile/test evidence, not a proof of memory safety.
Windows entries are cross-compiled; Windows runtime tests remain required.
New disk core files added by another session compile and have passing Linux
unit tests; application starts remain disabled. Regenerate after new wiring.

## Invariants reviewed

| Component                                 | Why unsafe / required invariant                                                                                                                             | Platform validation                                                                                                                      |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Windows ProcessHandle, snapshots, threads | Successful owned handle is closed exactly once; borrowed handles never close; minimal access masks                                                          | Windows core all-target Clippy/cross-check; native tests pending                                                                         |
| Windows process controls                  | GetProcessTimes checked on held handle; IsProcessCritical must succeed for disruptive actions; thread owner checked after opening; rollback retains handles | Lifetime mismatch/child tests on Linux; Windows tests compile                                                                            |
| Windows callbacks                         | EnumWindows lparam points to live stack EnumState for synchronous callback; no retention                                                                    | Source review; runtime pending                                                                                                           |
| Windows IP Helper                         | u32 backing matches POD row alignment; checked byte/count bounds and 16 MiB allocation cap; API owns no buffer memory                                       | Byte-order tests compile; runtime pending                                                                                                |
| Windows system snapshot                   | u64 backing, checked offset and struct extent, read_unaligned by value, 16 MiB bound, finite retries                                                        | Snapshot test compiles; runtime pending                                                                                                  |
| Windows Restart Manager                   | UTF-16 paths remain NUL terminated/alive through call; initialized vectors match count; session guard closes once; bounded retries/results                  | Dummy-file integration test compiles; runtime pending                                                                                    |
| Windows memory maps/modules               | Query only; writable initialized output buffers and exact lengths; checked forward progress; no process memory bytes exposed                                | Own-process tests compile; runtime pending                                                                                               |
| Windows SID lookup                        | LocalAlloc SID freed with LocalFree exactly once; fixed UTF-16 buffers/lengths obey API; no access-token privilege manipulation                             | Source and cross-compile                                                                                                                 |
| Windows disk counters                     | Device handle opened for read-only query, buffer size equals DISK_PERFORMANCE, closed once                                                                  | Cross-compile; runtime pending                                                                                                           |
| Linux signals                             | Positive checked pid; pidfd_open owned fd closed by OwnedFd; null siginfo plus zero flags; signal acts through fd, no numeric fallback                      | Child suspend/resume/kill and mismatch tests pass with normal OS access                                                                  |
| Linux priority                            | Enum maps to fixed nice values; kernel errors mapped, no elevation                                                                                          | Source review; numeric-PID race remains documented                                                                                       |
| Linux affinity                            | Initialized cpu_set_t, CPU indices < CPU_SETSIZE, current thread only, graceful failure                                                                     | Core tests and benchmark fake hooks; no calibration changes                                                                              |
| Linux clock ticks                         | sysconf scalar call; fallback for failed/nonpositive clock query                                                                                            | Linux core tests                                                                                                                         |
| Private-file test FIFO                    | NUL-terminated path owned inside exclusive test tempdir; never opens a real user FIFO                                                                       | Refuses special-file read without waiting                                                                                                |
| Emerging aligned disk buffers             | Allocation/deallocation must use identical checked Layout; nonnull exclusive owner; slices valid only for allocation lifetime; Send transfers ownership     | Not part of baseline executable; checked rounding now rejects extreme sizes; directory lifetime still needs review before IPC enablement |

No arbitrary pointer/address/length IPC, process-memory reading command, custom
privileged helper, native DLL loader command, or untrusted WGSL loader exists
at baseline. Windows memory-map inspection returns metadata, not memory bytes.
There is no first-party raw extern declaration; callbacks use the documented
Win32 ABI and bindings provide other FFI declarations.
