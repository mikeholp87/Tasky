# Security policy

This project is pre-release. Security fixes target the latest source and
latest 0.1.x release; older snapshots should be updated before further use.
Windows and Linux are supported targets. macOS is not yet supported.

Please use this repository's **Security → Report a vulnerability** private
reporting feature, if enabled. If it is unavailable, ask a maintainer for a
private reporting channel without posting vulnerability details publicly.
Do not put credentials, process dumps, full command lines or private
diagnostics in public issues.

Include the version/commit, OS, affected feature, required privileges, expected
and observed behavior, and a minimal harmless reproduction. Redact unrelated
machine and account identifiers. Please allow maintainers time to reproduce
and coordinate a fix before disclosure. No guaranteed response SLA is currently
published; an acknowledgement or fix date should not be assumed.

See [the application security model](docs/SECURITY.md),
[2026-11-03 audit findings](docs/archive/security-2026-11-03/SECURITY_AUDIT.md), and
[release checklist](docs/SECURITY_CHECKLIST.md).
